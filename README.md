Interactive Tableau dashboards analyzing Vancouver's restaurant landscape using Yelp data, exploring restaurant popularity, customer ratings, review trends, COVID-19 impacts, and user behavior.
# Vancouver Yelp Reviews Analysis | Tableau Data Visualization

## Project Overview

This project explores Vancouver's restaurant industry using Yelp business, review, and user data. Through interactive Tableau dashboards and data storytelling, the project aims to uncover patterns in restaurant popularity, customer satisfaction, online review trends, and user engagement.

## Key Analysis Areas

- **Restaurant Performance:** Analyze restaurant popularity, customer ratings, review counts, and cuisine categories across Greater Vancouver.
- **Interactive Geographic Analysis:** Visualize restaurant locations and explore geographic patterns using interactive maps and cuisine filters.
- **Review Trend Analysis:** Examine historical changes in Yelp star ratings and review distributions.
- **COVID-19 Impact Analysis:** Investigate how the pandemic influenced online review activity and customer feedback.
- **User Behavior Analysis:** Explore Yelp user engagement and review patterns.
- **AI-Assisted Data Storytelling:** Develop additional visualizations to investigate a specific question about Vancouver's restaurant industry.

## Tools & Skills

- **Tableau:** Interactive dashboards, geographic visualization, and data storytelling
- **Data Analysis:** Exploratory data analysis, trend analysis, and customer behavior analysis
- **Business Analytics:** Restaurant performance evaluation and customer insights
- **Data Visualization:** Dashboard design, filtering, and visual communication

## Business Value

This project demonstrates how customer-generated review data can support business decisions, identify restaurant market trends, and provide insights into consumer preferences and competitive positioning.
